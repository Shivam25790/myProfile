myProfile

This repository contains a Spring Boot MVC application (server-side Java + H2 DB). GitHub Pages only serves static sites and cannot run the Java backend.

How to run locally

  1. Install Gradle or generate the Gradle wrapper (run gradle wrapper locally).
  2. Start the app: ./gradlew bootRun (or gradle bootRun).
  3. Open the app at http://localhost:8080/profiles. H2 console: /h2-console (JDBC URL: jdbc:h2:mem:myprofiledb).

Deploying

To publish the running app publicly, deploy the Spring Boot application to a server/PAAS (Render, Railway, Heroku, AWS Elastic Beanstalk, Google Cloud Run, etc.). Alternatively, build a separate static frontend and host it with GitHub Pages while keeping the backend hosted elsewhere.

See README for more details.
